Genome wide phasing in routine diagnostic samples using long-read sequencing¶

Overview¶

This report evaluates genomic phasing using long-read sequencing data from the Genome in a Bottle (GIAB) reference materials and clinical sequencing datasets.

The analysis examines the ability of long-read sequencing to resolve variants onto their respective haplotypes, with a focus on phasing accuracy, completeness, and performance across different genomic contexts.

Data analysed¶

  • GIAB replicates — used as benchmark datasets with well-characterised variant and haplotype information.
  • Clinical long-read sequencing samples — used to assess phasing performance in real-world clinical sequencing data.

The results presented below summarise the phasing performance observed across these datasets.

    overlaps = snp_gr_autosomes.join(sample_gr)

# Function to calculate N50 from a list of lengths
def calc_n50(lengths):
    sorted_lengths = sorted(lengths, reverse=True)
    total = sum(sorted_lengths)
    cum_sum = 0

    for l in sorted_lengths:
        cum_sum += l
        if cum_sum >= total / 2:
            return l

    return 0

# Function to calculate phase block lengths from TSV
def get_block_lengths(bed_file):
    df = pd.read_csv(
        bed_file,
        sep="\t",
        header=None,
        names=["CHROM", "START", "END", "PS"]
    )
    
    allowed_chroms = ["chr" + str(i) for i in range(1, 23)]
    df_autosomes = df[df["CHROM"].astype(str).isin(allowed_chroms)]

    df_autosomes["length"] = df_autosomes["END"] - df_autosomes["START"] + 1

    return df_autosomes["length"].tolist()

results = []
phaseblock_lengths = []

for bed_file in phase_blocks_bed_files:
    lengths = get_block_lengths(bed_file)
    phaseblock_lengths = phaseblock_lengths + lengths
    n50 = calc_n50(lengths)
    sample = os.path.basename(bed_file).replace(".phase_blocks.bed", "")
    if "giab" in bed_file:
        sample_type = 'GIAB'
    else:
        sample_type = 'Clinical'
    results.append({

        "N50": n50,
        "Type": sample_type,
        "Phaseblocks": lengths
    })
